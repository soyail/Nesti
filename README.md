# 栖伴 Nesti

> 栖于桌边，伴你工作。
> Your little companion through the workday.

栖伴是一只住在桌面上的工作陪伴型数字生命。它通过桌面宠物、LLM 对话、长期记忆、主动关怀和粗粒度工作状态感知，提供低干扰、有温度、可持续的陪伴。

## 当前状态

项目处于早期设计阶段。当前仓库主要包含产品原则、架构边界和工程约定，技术栈与具体实现尚未确定。
