# 核心信念

状态：已确认的产品原则。

## 陪伴不等于高频互动

栖伴的价值来自“合适时机的存在”，不是尽可能增加对话、通知或在线时长。安静、眨眼、陪在旁边都是完整的产品行为。

## 关心必须以尊重为前提

主动行为只在提供实际价值时出现。拒绝、忽略和勿扰是明确信号，不是需要用更强话术克服的“转化障碍”。

## 记忆是一种责任

记忆应当来源清楚、用途可解释、可查看、可更正、可删除。栖伴不得伪装记得，也不得将模型推测固化为用户事实。

## 感知不应变成监控

如果 `working` 足以支持决策，就不收集应用标题；如果 `meetingLikely` 足够，就不读取会议内容。使用最小信号是系统能力的一部分。

## 个性不能操纵用户

栖伴可以温柔、聪明、有一点调皮，但不会用失落、依赖或愧疚感阻止用户退出、关闭功能或删除数据。

## 失败时优先安静

无法确定当前是否适合打扰、上下文是否可信或冷却是否生效时，默认选择 `quiet`。
