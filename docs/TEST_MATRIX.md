# 跨平台测试矩阵

## 文档状态

- 状态：Proposed
- 原则：优先覆盖会造成打扰、数据丢失、权限误用或无法退出的问题

## 建议环境

| 维度 | 最小覆盖 |
| --- | --- |
| macOS | 最新主要版本及前一版；Apple Silicon；如承诺则加 Intel |
| Windows | Windows 11 x64；如承诺则加 Windows 10/ARM64 |
| 缩放 | Windows 100%、125%、150%、200%；macOS Retina/非 Retina 显示组合 |
| 显示器 | 单屏、双屏、左右不同缩放、热插拔、主屏切换 |
| 网络 | 离线、高延迟、断线重连、代理/VPN |
| 权限 | 允许、拒绝、运行中撤销、系统升级后变化 |

## 性能预算

以下为待验证的 MVP 目标，技术栈确定后应用基准测试修正：

- 隐藏或安静时不持续以满帧率渲染。
- 空闲状态不进行高频系统轮询或连续 LLM 请求。
- 普通 UI 操作不被网络、存储或动画资源加载阻塞。
- 低电量/节能状态下可降低动画帧率和感知频率。

记录发布候选版的冷启动时间、空闲 CPU、稳态内存、崩溃率和重复提醒率，但遥测不得包含对话或桌面内容。

## 自动化分层

1. 共享领域逻辑在单元测试中覆盖，不为每个平台重复全部用例。
2. 平台适配器使用契约测试验证统一语义。
3. 窗口、权限、签名安装和升级使用真实操作系统端到端测试。
4. 每个发布候选版至少完成一次人工体验检查，确认宠物不遮挡工作区域且主动行为可忽略。
