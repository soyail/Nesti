# 产品判断

## 一句话定位

栖伴是一个低干扰的工作陪伴型桌面宠物，会在适当的时机提供简短、有上下文、可忽略的陪伴。

## 核心用户承诺

- 它会记住我主动告诉它的事，不会伪装记得。
- 它会关心我的状态，但不会让我感到被监控。
- 它会尊重拒绝、勿扰和安静时间。
- 它会解释自己为什么出现，并允许我关闭相关能力。

## 优先级原则

1. 少打扰优先于多互动。
2. 用户主动意图优先于系统预设任务。
3. 长期信任优先于短期留存或互动次数。
4. 粗粒度感知优先于精确监测。
5. 可解释、可关闭优先于“智能但不可控”。

## 成功信号

早期不以通知数量、日均对话轮次或使用时长作为唯一指标。更重要的信号包括：

- 用户保留主动关怀功能，而不是安装后立即关闭。
- 提醒被标记完成或稍后提醒，而不是长期直接忽略。
- 用户能正确说明栖伴收集什么、为什么收集。
- 用户愿意主动记录偏好、日常或工作回顾。

## 明确不做

- 不将栖伴设计为员工监控、绩效评估或工时考核工具。
- 不提供医疗诊断、治疗建议或健康结论。
- 不通过焦虑、愧疚或精确监测话术驱动行为。
- 不在默认情况下读取屏幕正文、键入内容、剪贴板或私人通信。

## 产品决策检查

新功能进入开发前，至少回答：

1. 它给用户的具体价值是什么？
2. 用户不回应或拒绝时，系统如何降低打扰？
3. 功能为什么需要当前数据和权限？
4. 用户如何关闭、延后、删除或导出？
5. 功能失败时，是否能安静、可恢复地降级？
