# Architecture Decision Records

ADR 用于记录会影响长期维护、安全、发布或多个模块的架构选择。

## 流程

1. 使用 `Proposed` 记录背景、建议、代价和验证要求。
2. 完成必要原型、风险审查和团队确认后改为 `Accepted`。
3. 方案被取代时标记 `Superseded`，保留原文档以便追溯。
4. ADR 只记录决策与后果，具体交付步骤放入执行计划。
