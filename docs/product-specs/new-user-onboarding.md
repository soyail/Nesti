# 新用户引导

状态：Draft

## 目标

让用户在几分钟内理解栖伴是什么、会做什么、不会做什么，并在不被迫一次性开放所有权限的情况下开始使用。

## 核心流程

1. 展示产品定位和“低干扰陪伴”承诺。
2. 选择基础个性化：称呼、宠物存在感/动效强度。
3. 选择是否开启喝水、活动和开工问候，并展示可调整频率。
4. 仅在选中功能需要时请求系统权限，先解释用途。
5. 展示暂停提醒、暂停感知、数据管理和退出入口。
6. 以一次可忽略的简短问候结束。

## 交互要求

- 允许跳过非必要步骤，且随后可在设置中完成。
- 不将权限拒绝表述为错误，只说明相关功能的降级。
- 权限说明和打开系统设置的操作必须匹配当前 macOS/Windows 版本，不展示另一平台的指引。
- 不默认勾选上传完整对话、桌面正文或产品分析数据。
- 引导完成前就可随时退出应用。

## 验收标准

- 用户可在不授予可选系统权限的情况下进入主界面。
- 每项权限都显示用途、收集范围和关闭影响。
- 提醒类型可单独关闭，不需要关闭整个产品。
- 完成引导后不在短时间内连续展示多个主动气泡。
