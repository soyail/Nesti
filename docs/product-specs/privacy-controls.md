# 隐私与控制

状态：Draft

## 目标

让用户能了解栖伴正在使用哪些数据，并能够以类型为单位暂停、关闭、导出和删除。

## 必要控制

- 暂停/恢复桌面感知。
- 暂停/恢复所有主动提醒。
- 按类型管理对话、日记、长期记忆、提醒历史和偏好。
- 查看本地数据目录和保留说明。
- 导出用户数据。
- 一键删除所有数据。
- 设置 LLM 上传禁用范围和脱敏偏好。

## 交互要求

- 每项开关说明它影响的功能，不用模糊的“提升体验”解释数据用途。
- 删除全部数据属于破坏性操作，需明确确认，但不得用情感化文案阻止用户。
- 删除或导出失败时展示具体失败范围，不伪装完成。
- 关闭感知或上传后，界面显示对应降级状态。

## 验收标准

- 用户可在不重启应用的情况下暂停感知和主动提醒。
- 删除操作覆盖主数据、索引、缓存和待重试队列。
- 导出不包含 API Key、加密密钥或未脱敏调试日志。
- 被禁止上传的数据类型不进入 LLM 请求、重试队列或遥测。
