# 安装、启动与更新

状态：Draft

## 目标

让 macOS 和 Windows 用户可以安全安装、启动、更新和卸载 Nesti，不需要不必要的管理员权限，不会在专注状态中被强制重启。

## 安装体验

- 安装包必须经过平台代码签名；macOS 官网版必须通过 Notarization。
- 安装不默认开启登录自启动，由用户在引导或设置中选择。
- 安装过程不请求与安装无关的桌面感知权限。
- 安装完成后首次启动进入新用户引导，不立即进行多次主动互动。

## 更新体验

1. 后台低频检查可用更新，失败时安静退避。
2. 告知用户版本、大致变更和是否需要重启。
3. 下载和校验可在后台完成，安装/重启需要尊重用户时机。
4. 在会议、演示、全屏、勿扰或存在未完成用户输入时不主动要求重启。
5. 更新失败后保留当前可运行版本，并提供简短重试或手动下载入口。

## 强制更新

默认不使用强制更新。只有存在已被利用的高危安全问题且旧版无法安全运行时才可考虑，仍应允许用户保存/导出数据并选择合适的重启时机。

## 卸载与数据

- 卸载前或隐私设置中清晰说明用户数据的默认处理。
- 应用内提供“删除所有数据”，覆盖主数据、索引、缓存和待上传/重试队列。
- 重新安装时如检测到保留数据，必须告知用户，不默默恢复旧记忆。

## 验收标准

- 干净安装、从上一个支持版本升级、更新中断恢复和卸载在两个平台均通过验证。
- 无效或被篡改的更新包无法安装。
- 更新失败不会造成无法启动、数据无法读取或提醒重复。
- 用户可以在勿扰或当前工作结束后再重启完成非紧急更新。
